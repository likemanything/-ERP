# 01 · 业务与术语

本系统服务「中国跨境卖家」：在 Amazon / Walmart / TikTok / Shopify 等平台开店，国内采购、国内仓或海外仓发货、通过头程把货发到 FBA 仓，
同时给**分销商**供货（一件代发 / 批发）。对标产品是**领星 ERP**，术语尽量与领星保持一致，方便用户迁移。

## 1. 业务主链路

```
店铺授权 ─▶ Listing 同步 ─▶ MSKU↔SKU 配对
                                  │
采购计划 ─▶ 采购单(审批) ─▶ 到货质检入库 ──▶ 本地仓库存（FIFO 批次：采购成本 + 物流成本）
                                                 │
            ┌────────────────────────────────────┼─────────────────────────────┐
            ▼                                    ▼                             ▼
   FBA 发货计划 ─▶ 货件出库 ─▶ 头程在途 ─▶ FBA 签收入库     自发货订单：审核锁库存 ─▶ 波次拣货 ─▶ 扫码验货发货
   （头程费用分摊进批次成本）           │                      ▲
                                        ▼                      │
                              FBA 订单发货结转成本      分销商门户下单（实时扣预存款）
                                        │                      │
                                        └──────▶ 利润报表（含平台费用、广告、退款、费用单） ◀────┘
补货建议：按销量 + 在途 + 库存 → FBA 发货建议 / 采购建议 → 一键生成计划
```

## 2. 各业务域要点

| 域 | 用户在做什么 | 关键规则 |
| --- | --- | --- |
| 店铺 shop | 授权平台店铺、同步数据 | 凭证 Fernet 加密，接口不回显；演示模式（`credentials.mode=demo`）生成确定性假数据；Amazon / Walmart / TikTok 店铺自动建平台虚拟仓（FBA / WFS / FBT，`shop/router.py::ensure_fba_warehouse`） |
| 产品 product | 本地 SKU、组合产品、辅料、Listing 配对 | 1 个 MSKU 可配对「N 件」本地 SKU（多件装 `pair_quantity`）；组合产品（bundle）是虚拟套装，出入库时展开为子件，**本身不持有库存** |
| 采购 purchase | 计划 → 采购单 → 审批 → 下单 → 分批到货 → 结单；退货；请款付款 | 外币采购按下单汇率折算本位币；运费/杂费按金额分摊进入库成本（物流成本部分）；次品单独计数 |
| 仓库 warehouse | 库存查询、出入库单、调拨、盘点、库位、批次库龄 | 库存 = 实物 `qty_on_hand`、锁定 `qty_locked`、可用 = 实物 − 锁定、次品、在途；本地仓默认不允许负库存，FBA 虚拟仓允许负数 |
| FBA fba | 发货计划 → 货件 → 发货 → 分批签收；头程费用 | 头程费用按计费重/体积/数量/货值分摊；账单后补时重新分摊并修正剩余批次成本 |
| 补货 replenishment | FBA 发货建议、采购建议 | 公式见 §5 |
| 订单 order | 多平台订单、自发货处理、退货退款 | 状态机见 §3；FBA 订单发货时从 FBA 仓 FIFO 结转成本；平台后台直接发货的自发货单自动补扣库存 |
| 仓储作业 fulfillment | 波次拣货、拣货单/装箱单、扫码验货发货、运单号导入、标签打印 | 只有「待发货 + 未挂起 + 自发货」的订单能进波次；波次内订单全部发货后自动完成 |
| 加工单 assembly | 组装（子件 → 成品）/ 拆分（成品 → 子件） | 成品为普通产品；组装成本 = 子件 FIFO 成本 + 加工费；拆分按子件参考采购成本比例分摊 |
| 分销 distribution | 给分销商开账号；分销商在门户看目录、下单、充值 | 见 §4 |
| 审批 approval | 采购单 / 请款单 / 分销充值的多级审批 | 金额（本位币）≥ 流程门槛时走流程（取门槛最高的一个）；无匹配流程 → 原有单级审批（按权限） |
| 物流 logistics | 物流商、渠道运费规则、比价 | 首重续重 / 按重量 / 按体积 / 按件；材积除数；最低收费 |
| 财务 finance | 利润报表、结算明细、费用单、库存估值、汇率 | 结算导入后用实际佣金 / FBA 费替换预估；按月度汇率折算本位币 |
| 广告 ads | 广告日报、ACoS / ROAS | 广告费按日期 × MSKU 计入利润 |
| 报表 report / 看板 | 销售统计、库龄、周转 | 只读聚合 |
| 系统 system | 企业、用户、角色、店铺数据权限、日志、参数、消息 | 管理员全权限；用户可限定可见店铺 |

## 3. 状态机

**销售订单 `SalesOrder.status`**

```
pending(待付款) ──▶ to_audit(待审核) ──审核:分配仓库+锁库存──▶ to_ship(待发货) ──发货:FIFO出库+结转成本──▶ shipped ──▶ delivered
        │                 │  ▲ 反审核(释放锁定)                     │
        └────────── cancelled(取消：释放锁定；分销订单自动退款) ◀────┘
FBA 订单：pending ──平台发货──▶ shipped（从 FBA 仓结转成本）──▶ delivered
挂起 is_on_hold 是独立标记：挂起的订单不能审核 / 进波次 / 扫码发货
```

**其他单据**

| 单据 | 状态流转 |
| --- | --- |
| 采购单 | draft → pending_approval → approved → ordered → partial → received → closed；rejected（可改后重提）；cancelled |
| 请款单 | pending → approved → paid；rejected；cancelled |
| 出入库单 | draft → pending → completed（调拨：pending → in_transit → completed）；cancelled |
| FBA 货件 | draft → shipped → receiving → closed；cancelled |
| 退货单 | pending → completed；cancelled |
| 拣货波次 | picking → picked → completed；cancelled（未发货订单退回待发货） |
| 加工单 | draft → completed；cancelled |
| 审批实例 | pending → approved / rejected；单据作废或重新提交 → cancelled |
| 分销充值 | pending → approved（入账）/ rejected |

## 4. 分销业务规则

- **分销商**：等级（折扣率）、结算币种（产生流水后不可改）、预存余额 `balance`、授信额度 `credit_limit`；**可用额度 = 余额 + 授信**。
- **价格**：商品的等级专属价 ＞ 分销基础价 × 等级折扣；按汇率折算为分销商币种。
- **下单**：报价 = 货款 + 运费（渠道运费 × (1 + 加价率)，仅代发）+ 操作费（每单 + 每件，仅代发）；**下单即扣款**，可用额度不足拒单。
- **订单落库**：每个分销商有一个虚拟店铺（平台 `distribution`），分销订单就是普通 `SalesOrder`（带 `distributor_id`、`distribution_type`、`charge_detail`），因此锁库存、波次、发货、成本、利润全部复用。
- **退款**：取消订单全额退回（幂等）；退货退款按金额退回，累计不超过扣款；`charge_detail.refunded` 记录累计退款额。
- **资金流水**：`DistributorTransaction`（recharge / order / refund / adjust），带行锁，余额快照 `balance_after`。
- **账号隔离**：分销商用户 `user_type=distributor`，只能访问 `/api/v1/portal/*`；也可用 API Key（`X-Api-Key`）调用门户接口；门户永不返回成本。

## 5. 核心公式

**利润（本位币，已发货订单口径）**

```
毛利润 = 销售额(商品 + 买家运费 − 促销) − 退款 − 平台佣金 − FBA 配送费 − 其他订单费用 − 广告费
       − 采购成本 − 头程/物流成本（FIFO 结转）+ 退货回库成本 − 自发货运费 − 平台其他费用 − 费用单
订单预估利润：未发货时成本按产品参考采购成本 × 数量、运费按预估运费估算
```

**补货**

```
日均 = (近7天日均×w7 + 近14天日均×w14 + 近30天日均×w30) / (w7+w14+w30) × 增长系数
建议发货量 = 日均 × (头程时效 + 安全天数 + 备货天数) − (FBA 可售 + 预留 + 入库在途)
建议采购量 = 日均 × (采购交期 + 质检 + 头程 + 安全 + 备货) − (本地可用 + FBA 总库存 + 采购在途 + 待处理计划)，按起订量向上取整
```

**成本**：每个库存批次记录 `unit_purchase_cost`（采购成本）与 `unit_freight_cost`（物流/头程成本），出库按 FIFO 消耗并返回两部分成本；
调拨、FBA 发货、退货、加工都沿用来源批次的成本层。

## 7. 术语表

| 术语 | 含义 |
| --- | --- |
| SKU | 本地产品编码（`Product.sku`），库存与成本的最小单位 |
| SPU | 款号，多个变体 SKU 共用 |
| MSKU | 平台卖家 SKU（Listing 的 seller sku），需与 SKU 配对 |
| ASIN / FNSKU | 亚马逊商品编号 / 亚马逊仓储条码（入 FBA 仓必须贴 FNSKU 标签） |
| Listing | 店铺上架的商品（MSKU 维度） |
| 配对 | MSKU → SKU 的映射，可「1 MSKU = N 件 SKU」（多件装） |
| 组合产品 / 套装 | 虚拟 SKU，出库时拆成子件；与加工单「组装成品」不同，后者是真实成品库存 |
| 辅料 | 包材等，不能上架分销，可作为加工子件 |
| FBA / FBM | 亚马逊仓发货 / 卖家自发货。系统中平台仓发货（含 Walmart WFS、TikTok FBT）统一记为 `FBA` |
| 头程 / 尾程 | 国内 → 平台仓/海外仓的运输 / 海外仓 → 买家的配送 |
| 计费重 | max(实重, 体积重)，体积重 = 长×宽×高 / 材积除数 |
| 批次 / 成本层 | 每次入库形成一个批次，记录剩余数量与单位成本，出库按先进先出消耗 |
| 锁定库存 | 订单审核后为其预留的库存，发货时从锁定中扣减 |
| 波次 | 把多张待发货订单合并拣货的作业批次 |
| 拣货单 / 装箱单 / 箱唛 | 按库位汇总的拣货清单 / 随包裹的发货清单（不含价格）/ 外箱标签 |
| 一件代发 / 批发 | 分销两种模式：我方直接发给终端客户 / 整批发给分销商 |
| 授信额度 | 允许分销商欠款的上限 |
| 本位币 | 企业记账币种（`Tenant.base_currency`），成本与利润统一折算到本位币 |
| ACoS / TACoS / ROAS | 广告花费 / 广告销售额；广告花费 / 总销售额；广告销售额 / 广告花费 |
| 结算明细 | 平台结算交易（佣金、FBA 费、仓储费、退款等），用于替换预估费用 |
| 请款 / 应付 | 采购向财务申请付款 / 供应商未付金额汇总 |
| 或签 / 会签 | 审批节点任一审批人通过即可 / 全部审批人通过 |
