# ADR-0003：分销订单复用销售订单（每个分销商一个虚拟店铺）

- 状态：已采纳
- 日期：2026-10-01

## 背景

分销订单与平台订单在履约上完全相同（审核锁库存、拣货、发货、退货、成本、利润），差别只在于订单来源与资金结算（预存款扣款 / 退款）。

## 决策

- 为每个分销商自动创建一个虚拟店铺（平台 `distribution`），分销订单写入 `SalesOrder`，增加 `distributor_id`、`distribution_type`、`charge_detail` 三个字段。
- 资金在独立的 `DistributorTransaction` 流水中处理：下单扣款、取消全额退款（幂等）、退货按金额退款（不超过扣款）、补扣 / 部分退款。
- 订单取消 / 退货完成时由订单模块调用分销模块的钩子（`refund_order` / `credit_return`）。
- 门户（`/portal/*`）与后台完全隔离：分销商账号 `user_type=distributor`，不能访问后台接口；也可用 API Key 接入。

## 备选方案

- 独立的分销订单表 + 再生成出库单：履约逻辑要复制一份，波次 / 扫码 / 利润报表都要适配。

## 影响

- 波次、扫码发货、利润报表等新功能自动覆盖分销订单。
- 订单模块对分销模块有少量反向依赖（取消 / 退货钩子），修改这两处要同时看分销测试。
- 分销订单金额为分销商币种，利润按汇率折算本位币，与平台订单一致。
