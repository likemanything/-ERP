# ADR-0004：审批引擎命中流程才启用，否则回退单级权限

- 状态：已采纳
- 日期：2026-10-01

## 背景

原系统的采购单、请款单、分销充值都有「按权限的单级审批」，大多数小团队够用；部分企业需要按金额分级、多人会签。
新能力不能破坏已有企业的使用方式。

## 决策

- 审批流程按「单据类型 + 金额门槛（本位币）」配置，可多级，每级指定人员或角色，或签 / 会签。
- 单据提交时 `approval.start()`：匹配到流程（门槛最高者）才生成审批实例；否则返回 `None`，单据沿用原来的单级审批。
- 审批时 `approval.act()` 返回 `None`（无实例 → 调用方检查原权限）/ `pending` / `approved` / `rejected`；单据自身的状态变化仍由各业务模块完成。
- 流程在提交时快照到实例，后续修改流程不影响进行中的审批；管理员可代审批（记录在意见中）。

## 影响

- 不配置流程的企业行为完全不变。
- 审批接口依赖从 `perm(...)` 改为 `get_ctx`，权限判断下沉到 service。
- 新增单据类型需要在多个位置接入（见 06-recipes「新增审批单据类型」）。
