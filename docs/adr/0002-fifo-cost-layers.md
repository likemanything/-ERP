# ADR-0002：FIFO 批次成本层，采购成本与物流成本分开

- 状态：已采纳
- 日期：2026-10-01

## 背景

跨境卖家最关心「每个 MSKU 真实赚多少钱」，成本由采购价、国内运杂费、头程运费 / 关税组成，且同一 SKU 不同批次成本差异大（汇率、运费波动）。
领星使用批次成本（先进先出）并区分采购成本与头程成本。

## 决策

- 每次入库生成 `InventoryBatch`，记录 `unit_purchase_cost` 与 `unit_freight_cost`（本位币）。
- 出库按 FIFO 消耗批次，返回两部分成本；调拨、FBA 发货、签收、退货、加工都通过 `inbound_layers` 保留来源成本层并叠加新的物流成本。
- 头程费用后补时重新分摊，并修正目的仓**剩余**批次成本（已售部分不追溯）。
- 所有库存变动只能经过 `InventoryService`，它同时维护余额、批次、流水。

## 影响

- 利润按订单行精确到采购 / 物流两部分；库存估值可按批次计算。
- 负库存（FBA 虚拟仓、平台直发补扣）时，超出部分按参考成本出库，后续入库先冲抵负数。
- 任何绕过 `InventoryService` 的改动都会破坏成本与流水一致性（`audit_order(force=True)` 是已知例外）。
