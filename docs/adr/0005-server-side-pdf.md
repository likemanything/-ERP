# ADR-0005：打印由后端生成 PDF（reportlab）

- 状态：已采纳
- 日期：2026-10-01

## 背景

需要打印 FNSKU / SKU 标签（热敏 60×30、A4 标签纸）、箱唛、拣货单、装箱单。浏览器 HTML 打印在不同打印机 / 缩放设置下尺寸不稳定，标签打印对毫米级尺寸要求严格。

## 决策

- 后端用 reportlab 生成 PDF：Code128 条码、精确的页面尺寸、A4 标签纸网格（支持跳过已用格子）。
- 中文默认用内置 CID 字体（零依赖），生产通过 `ERP_PDF_FONT_PATH` 嵌入 TTF/TTC（Docker 镜像内置文泉驿正黑）。
- 前端 `openPdf()` 在新窗口打开 blob，由浏览器 PDF 预览打印。

## 影响

- 打印结果与设备无关，热敏打印机按 PDF 页面尺寸出纸。
- 新模板需要用 reportlab 编写，版式验证要转图片人工查看（`pdftoppm`）。
- PDF 生成在请求线程中同步完成，单次标签数量限制 5000 张。
